# PT physician-order templates

Use these as structural references for the exact Kinnser template names and section order. Preserve the live template wording unless the clinician directs a change. Populate only supported facts.

## Shared marker and exclusion rules

- A selected square is always `[x]`; an unselected square is `[  ]`.
- Preserve `[x] ORDER READ BACK AND VERIFIED WITH PHYSICIAN`.
- Remove the entire `[  ]  Edema Management Training` and `[  ]  Pressure Ulcer Prevention Training` lines by default.
- Keep either excluded line only when the clinician explicitly requests it or the pt. is documented as bedbound and the intervention is supported. Mark it `[x]` only when actually ordered.
- Keep Order Summary blank unless explicitly dictated.
